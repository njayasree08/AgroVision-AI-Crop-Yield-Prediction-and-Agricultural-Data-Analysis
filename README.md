# AgroVision AI - Crop Yield Prediction and Agricultural Data Analysis

A beginner-friendly, end-to-end data mining project: a multi-page **Streamlit** dashboard that explores agricultural
data, **classifies** yield categories (KNN, Naive Bayes, Decision Tree), **clusters** similar records
(Agglomerative clustering with a dendrogram) and **predicts** crop yield (Linear Regression, Random Forest, XGBoost).

> **Synthetic data notice.** The built-in dataset (700 records) is generated by `src/data_generator.py` with a fixed
> random seed. It follows plausible, simplified agronomic rules but is **not real field data**. Results demonstrate
> the workflow; they do not show how well the models would perform on real farms.

## Objectives

* Explore and clean agricultural data (missing values, duplicates, inconsistent categories, outliers).
* Classify yield into Low / Medium / High and compare three algorithms fairly.
* Discover groups of similar records with hierarchical clustering and interpret them.
* Predict numeric yield with three regression algorithms and analyse the errors.
* Present everything through interactive charts, downloadable tables and an HTML report.

## Data mining techniques and algorithms

1. **Classification** - KNN, Gaussian Naive Bayes, Decision Tree on `Yield_Category`.
2. **Clustering** - Agglomerative (hierarchical) clustering; ward / complete / average / single linkage.
3. **Regression** - Linear Regression, Random Forest, XGBoost on `Crop_Yield`.

If `xgboost` is not installed, scikit-learn's `HistGradientBoostingRegressor` is used automatically and is labelled
as a substitute everywhere in the app.

## Dataset

700 records, 17 columns (see [`data/data_dictionary.md`](data/data_dictionary.md)). The target category
`Yield_Category` is derived from `Crop_Yield` using the 33rd and 67th percentiles (three near-equal classes).
The data deliberately include a few missing values, inconsistent spellings and impossible values so the cleaning
step is meaningful.

## Architecture and workflow

```
data/agricultural_data.csv
        |  data_loader (read, validate)  ->  preprocessing.prepare_dataset
        |        fixed-rule cleaning (ranges, spelling, duplicates)  +  Yield_Category
        v
 shared stratified train/test split (seed 42)
        |
        +--> classification.py  Pipeline[impute -> one-hot -> scale -> model]
        +--> regression.py      Pipeline[impute -> one-hot -> scale -> model]
        +--> clustering.py      impute -> one-hot -> scale -> Agglomerative (no target used)
        v
 evaluation.py (metrics, rankings, summaries)  ->  visualization.py (Plotly/Matplotlib)
        v
 app.py + pages/*.py (Streamlit)   |   models/*.joblib   |   outputs/*.csv
```

**Leakage prevention:** imputation, scaling and encoding live inside scikit-learn Pipelines fitted on the training
split only; `Crop_Yield`, `Yield_Category` and `Record_ID` are never inputs; clustering ignores yield information
(yield is used only to describe clusters afterwards).

**Class imbalance:** stratified split, macro-averaged metrics, optional `class_weight="balanced"` for the tree.

## Evaluation metrics

* Classification: accuracy, precision, recall, F1 (macro and weighted), confusion matrix, classification report,
  training/prediction time, 5-fold CV macro-F1 on the training set.
* Clustering: silhouette score (only when valid), Davies-Bouldin index, cluster sizes and profiles.
* Regression: MAE, MSE, RMSE, R2, training time.

All numbers are computed from real predictions; nothing is hard-coded.

## Installation (Windows, Visual Studio Code)

Install **Python 3.10 - 3.12** from python.org (tick "Add Python to PATH"). Open the project folder in VS Code
(`File > Open Folder`) and open the terminal (`Terminal > New Terminal`).

**1. Create and activate a virtual environment**

Command Prompt:
```bat
python -m venv .venv
.venv\Scripts\activate.bat
```
PowerShell:
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```
If PowerShell blocks the script, run once: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, or just use Command Prompt.

**2. Install dependencies**
```bat
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**3. Generate the 700-record dataset** (a ready-made copy is already in `data/`)
```bat
python generate_data.py
```

**4. Train the models** (optional here; the Prediction page can also do it with one click)
```bat
python train_models.py
```
This prints the three comparison tables, saves complete pipelines to `models/` and result tables to `outputs/`.

**5. Start the application**
```bat
streamlit run app.py
```
Your browser opens at http://localhost:8501. Stop with `Ctrl+C`.

**6. Run the tests**
```bat
python -m pytest
```

### Troubleshooting

* `streamlit` is not recognised -> the virtual environment is not active; repeat step 1's activation command.
* `xgboost` fails to install -> remove that line from `requirements.txt`; the app falls back to HistGradientBoosting.
* Models "could not be read" after upgrading scikit-learn -> run `python train_models.py` again.

## Upload your own data

Dataset Explorer > "Upload your own CSV". Required columns: `Crop_Type, Season, Area_Hectares, Annual_Rainfall_mm,
Average_Temperature_C, Soil_Type, Soil_pH, Nitrogen, Phosphorus, Potassium, Fertilizer_Usage, Irrigation_Type,
Previous_Year_Yield, Crop_Yield` (at least 50 rows). Files are only parsed as CSV text (never executed). Click
"Retrain" on the Prediction page afterwards to build models for the new data.

## Limitations

* Synthetic data: relationships are those the generator encodes, so metrics are optimistic and not transferable.
* Yield categories are percentile-based (relative), not agronomic standards.
* Mixed crops are modelled together with simple one-hot features; no spatial, weather-time-series or satellite data.
* Naive Bayes assumes independent, Gaussian features; this is violated here (see the Classification page).
* Clustering silhouette scores are modest because records form gradients rather than separate groups.
* Saved models are pickles; load only files created on your own machine.
